# PotencIA Soluciones

Contenedor técnico de productos y prototipos digitales de PotencIA Academy.

## Productos públicos

- `potencia-tools/` — PotencIA Tools. Herramientas de IA aplicada para prompts, automatizaciones y agentes.
- `brujula-potencia/` — Brújula PotencIA. Experiencia de reflexión con rutas F.O.C.U.S. y La Sabiduría del Ajolote.

## Estructura interna

- `staging/` — versiones de prueba y checkpoints técnicos. No debe enlazarse desde la portada pública.
- `robots.txt` — excluye staging y otras áreas internas de indexación.

## Publicación

La raíz del repositorio funciona como hub técnico de PotencIA Soluciones y enlaza a cada producto mediante rutas relativas. Esto permite renombrar el repositorio sin modificar las rutas internas.

Checkpoint previo a la reorganización: rama `checkpoint-before-potencia-soluciones-rename-2026-09-09`.

> Hosting técnico temporal. La entrada de marca para usuarios puede mantenerse en potenciaacademy.com mediante una página puente.
