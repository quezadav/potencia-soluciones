# PotencIA Soluciones

Contenedor técnico de productos y prototipos digitales de PotencIA Academy.

## Entrada oficial

La puerta de marca para usuarios es:

`https://potenciaacademy.com/potencia-soluciones/`

Este repositorio mantiene el **hosting técnico temporal** de las aplicaciones públicas. La página en PotencIA Academy aporta branding, contexto y navegación hacia cada producto.

## Productos públicos

- `potencia-tools/` — PotencIA Tools. Herramientas de IA aplicada para prompts, automatizaciones y agentes.
- `brujula-potencia/` — Brújula PotencIA. Experiencia de reflexión con rutas F.O.C.U.S. y La Sabiduría del Ajolote.

PotencIA Tools y Brújula PotencIA son productos distintos dentro de la sombrilla PotencIA Soluciones.
